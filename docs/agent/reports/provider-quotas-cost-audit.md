# Квоты провайдеров и аудит стоимости AISAD

Проверено 22 октября 2026 года. Агрегированная выборка стоимости зафиксирована в 12:15 МСК; значения живых квот меняются.

## Что добавлено

Компактная строка колец **Claude / Codex / Grok** показывает остаток квоты. Наведение или клик открывает карточку с процентами и временем сброса всех доступных окон:
- Claude Code: пятичасовое, недельное и модельные недельные окна, включая Fable.
- Codex: окна из `account/rateLimits/read`. В проверенном аккаунте сервер вернул только недельное окно; пятичасовое не выдумывается.
- Grok: процент из `_x.ai/billing` и фактические границы периода. Недельный и месячный периоды различаются по полной длине, а не по оставшемуся времени.

В работающем приложении запросы повторяются примерно раз в минуту, отсчёт сброса — каждые 30 секунд. Есть ручной Refresh. Наведение не отправляет запросы; единая кнопка Refresh обновляет расходы и квоты, сохраняя интервалы провайдеров. HTTP 429 сохраняет cooldown; `Retry-After: 0` получает безопасную паузу 5 минут.

При временной ошибке последняя квота остаётся серой с подписью Last known и исходным временем. После ошибки входа квота убирается. Прошедшее время сброса даёт Refresh needed, без автоматического подставления новой квоты 100%.

Внешнее кольцо показывает краткосрочное окно (обычно 5 часов), внутреннее — общее недельное. Дополнительные модельные окна остаются в карточке без третьего кольца; исчерпание любого окна отмечается предупреждением. Второй вкладки и полос квот нет; месячная полоса денежного бюджета сохраняется.

Используется существующий вход в CLI/Keychain. AISAD не выполняет login/logout, не обновляет токены, не меняет настройки входа и не импортирует браузерные cookies. Значения credentials не входят в отчёты, логи или файлы AISAD.

## Результат проверки стоимости

На выборке **37 131** наблюдения: Claude — 22 393, Codex — 14 738.
У каждого наблюдения есть назначенная оценка цены; часть назначений содержит допущения ниже.

Проверены инварианты:
- input = uncached + cache read + cache write;
- total = input + output;
- стоимость совпадает с суммой денежных составляющих;
- верхняя граница стоимости не меньше нижней.

Нарушений: **0**. В этой выборке нет неизвестных цен моделей, неизвестных TTL записи кэша или ценовых диапазонов. Codex cache writes в реальной выборке отсутствуют.

Каталог models.dev обновлён 22 октября: 58 моделей. Встроенный резервный каталог дополнен GPT-6.1 Sol, GPT-6 Sol/Luna и Claude Opus/Sonnet/Haiku 5.5. Проверки содержат независимые денежные примеры для входа, cache read/write, выхода, Fast/Flex/Batch/Ultrafast и границ длинного контекста. Тарифы сверены с [OpenAI pricing](https://developers.openai.com/api/docs/pricing) и [Claude pricing](https://platform.claude.com/docs/en/about-claude/pricing).

Исправлены:
- Grok `costIsPartial` теперь помечает денежный итог как неполный.
- Для новых моделей резервного каталога заданы тарифы и поддерживаемые режимы; Ultrafast получает отдельный множитель.
- Закрывается ответ HTTP 304 при проверке каталога цен.

Отдельно проверены Grok totals: 207 завершённых ходов в 51 сессии, известный subtotal $166.9083655 и один неполный ход. Перевод ticks в USD использует 10¹⁰ ticks за доллар, как описано в [xAI cost tracking](https://docs.x.ai/developers/cost-tracking). Эти provider-reported суммы остаются отдельно от API-переоценки Claude/Codex.

## Границы точности

**576 наблюдений** не содержат подтверждённого тарифного режима: применяется явно отмеченное предположение Standard.

**3 281 наблюдение `codex-auto-review`** используют существующую оценку по аналогу GPT-5.6 Luna. Точная публичная API-цена внутреннего имени не подтверждена. Эта оценка сохранена как допущение, а не доказанный расход. Для входа через ChatGPT OpenAI отдельно называет такие проверки [бесплатными для подписки](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans).

История оценивается по текущему каталогу. Исторические списания, персональные скидки, налоги и не записанные в логах платные операции не восстанавливаются. Поэтому корректная арифметика и полное покрытие моделей подтверждают API-эквивалентную оценку в её заявленных границах.

Квоты подписок получены у провайдеров напрямую и не рассчитываются из этих долларов. Для Claude и Grok используются внутренние поверхности существующих клиентов; при изменении протокола адаптер может потребовать обновления.
